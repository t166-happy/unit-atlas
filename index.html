安裝換算宇宙

iPhone／iPad：以 Safari 開啟本站，點「分享」→「加入主畫面」→「加入」；若出現「作為網頁 App 開啟」，請開啟。

Android：以 Chrome 開啟本站，點右上角選單 →「加入主畫面」或「安裝應用程式」，再確認安裝。

首次請保持連網，等候頁尾顯示「離線資源已備妥」，再從主畫面圖示開啟。清除瀏覽器資料或系統回收網站儲存空間後，需要重新連網載入。所有換算均在裝置內進行；本站不設帳號、不使用 API 金鑰或分析追蹤服務。
